\begin{abstract}
Legal AI agents may be optimized for client-favorable outcomes, but professional legal competence also requires role-specific process constraints. We introduce SettlementEthicsGym, a synthetic interactive benchmark for measuring reward-induced misrepresentation in civil settlement negotiation. Each episode provides hidden truth tables, role-specific case files, bargaining utilities, and rule-inspired truthfulness labels distinguishing material false statements from permissible negotiation posturing. In real LLM runs over a 48-scenario stress split, stress best-of-$N$ selection produces deterministic material misrepresentation in 6.25--14.6\% of episodes depending on selector and sample budget. A deterministic rewrite shield reduces measured material and severe violations to 0/48 episodes, but blindspot auditing shows this zero is detector-aligned rather than evidence of eliminated misconduct. On a 24-scenario blindspot split, a GPT-4.1 judge flags 63/390 unverified transcript rows, including deterministic-shield rows; 58/63 flagged transcript rows survive majority support across GPT-4.1 default, strict, and sensitive rubrics, and an independent o4-mini judge flags a conservative subset of 11/63. A fact-grounded verifier shield reduces GPT-4.1 transcript flags to 4/196. These results suggest that SettlementEthicsGym can expose evaluator overfitting and mitigation tradeoffs while making label uncertainty explicit.
\end{abstract}

\section{Introduction}

Settlement negotiation is a useful stress test for legal-agent evaluation because it is adversarial, partially observable, and outcome driven. A system rewarded only for client settlement utility may discover that inducing false beliefs improves bargaining results, a domain-specific instance of reward hacking and overoptimization concerns studied in AI safety \citep{amodei2016concrete,gao2022scaling}. Existing legal-negotiation benchmarks primarily ask whether agents can reach settlements \citep{settlebench,negotiationarena}. SettlementEthicsGym asks whether agents can reach settlements without misrepresenting material facts under optimization pressure.

The benchmark is not a source of legal advice and does not decide real lawyer discipline. It uses synthetic disputes and a rule-inspired taxonomy grounded in the distinction between impermissible false material statements and ordinary negotiation posturing under professional-responsibility rules such as truthfulness to others, client authority over settlement, and confidentiality \citep{aba41,aba12,aba16,aba439}. The current implementation focuses on civil settlement negotiation, role-specific hidden facts, deterministic ethics traps, real LLM agents, best-of-$N$ inference-time optimization, deterministic and verifier-based shields, and audit tooling for adjudicating evaluator disagreements.

\section{Benchmark Design}

Each scenario contains public facts, private files for the evaluated agent and opponent, reservation values, explicit truth-table facts, allowed puffery examples, forbidden pattern mappings, and gold utterance labels. The environment records structured actions with a public message, offer, requested information, disclosures, and self-reported assertions. A hybrid threshold opponent uses deterministic reservation logic and scenario-specific belief updates when material claims are believed.

\paragraph{Ethics labels.}
The current evaluator supports labels including \texttt{FALSE\_MATERIAL\_FACT}, \texttt{FALSE\_STATEMENT\_OF\_LAW}, \texttt{MISLEADING\_HALF\_TRUTH}, \texttt{PERMISSIBLE\_PUFFERY}, \texttt{PERMISSIBLE\_OPINION\_OR\_VALUE\_ESTIMATE}, and \texttt{UNSUPPORTED\_BUT\_NOT\_FALSE}. The primary violation threshold is severity at least 3.

\paragraph{Optimization pressure.}
The benchmark supports both no-API controls and real LLM agents. The no-API MVP compares honest scripted negotiation, deliberately deceptive calibration, utility-only best-of-$N$ selection, utility-minus-ethics best-of-$N$ selection, and a rewrite shield. The LLM-facing implementation uses structured JSON actions, zero-shot prompting, ethics prompting, utility prompting, stress utility prompting, shielded utility prompting, fact-grounded verifier shielding, and best-of-$N$ candidate selection with either utility-only or utility-minus-ethics selectors. Candidate-level logs preserve selected and rejected best-of-$N$ outputs for later audit.

\section{Current Implementation}

The repository now includes a Python package named \texttt{segym}; Pydantic schemas; YAML scenario loading and validation; a deterministic ethics evaluator; an OpenAI-compatible LLM negotiator; an LLM judge; scripted honest and deceptive agents; best-of-$N$ selectors; deterministic and LLM-verifier rewrite shields; a hybrid threshold opponent; an environment loop; run, analysis, audit, adjudication, and table-export scripts; and unit tests that run without internet or API keys.

The current seed set has eight scenarios across personal injury, employment, contract, debt collection, housing, and client-authority edge cases. These cover false insurance limits, fabricated witnesses, fabricated video evidence, false payroll records, false delivery records, false limitations status, false notice service, and authority misrepresentation. A generated 24-scenario split varies these families and amounts; a stress matrix adds higher-temperature utility-pressure prompts and larger best-of-$N$ candidate pools.

\paragraph{Audit and uncertainty protocol.}
All headline run tables are generated from non-fake run metadata. Episode-level deterministic rates use the deterministic evaluator replayed over final transcript messages. Candidate-level and transcript-level audits use sampled rows from transcripts and best-of-$N$ candidate logs. LLM-judge audits provide scenario facts, role information, and the public message, but not deterministic forbidden-pattern labels. We report Wilson 95\% intervals for binomial rates and keep deterministic, single-judge, multi-judge sensitivity, and optional external-adjudication fields separate. The repository exports \texttt{paper/tables/headline\_claims.csv} so each headline rate has an explicit numerator, denominator, evaluator, confidence interval, and adjudication status.

\paragraph{48-scenario stress matrix.}
The initial generated split produced too few unsafe single-sample outputs to stress mitigations. We therefore expanded to a 48-scenario stress split, added a stress utility prompt that explicitly rewards client utility and bargaining pressure while preserving the truthfulness rule, and increased best-of-$N$ sampling to $N=8$. Table~\ref{tab:llm-stress} reports the main 48-scenario matrix. Stress utility prompting produced deterministic material violations in 4.2\% of episodes. Stress utility best-of-$N$ produced violations in 14.6\%, while stress ethics-aware best-of-$N$ produced violations in 6.25\%. Every best-of-$N$ episode had at least one safe candidate available, but utility-only selection still selected an unsafe candidate despite a safe alternative in 14.6\% of episodes. This motivates candidate-level filtering rather than relying on a scalar ethics penalty alone.

\paragraph{Scaling and mitigation.}
Table~\ref{tab:scaling-shield} summarizes the completed scaling and shield-ablation runs. Increasing sample budget from $N=8$ to $N=16$ did not improve safety: utility-only $N=16$ produced 12.5\% material violations, and ethics-aware $N=16$ produced 14.6\%. In a lambda sweep for ethics-aware $N=8$, $\lambda=0.25$ produced the lowest deterministic material violation rate among tested values, while $\lambda=0.5$ and $\lambda=2.0$ were worse. The rewrite shield reached 0/48 deterministic material violations in both the main stress matrix and the shield ablation, whereas warn-only left 8.3\% material violations and block preserved safety at substantially lower utility.

The zero shield rows should be interpreted narrowly. They are zero deterministic-evaluator violations, not proven zero misconduct. The rewrite shield uses deterministic findings to decide whether to rewrite, so this result is partly detector-aligned. We therefore report Wilson intervals and separately audit shield outputs with LLM judges and released review packets.

\paragraph{Cross-model replication.}
We replicated the core stress matrix with GPT-4.1-nano. The smaller model had higher settlement rates and utility in this benchmark, but the qualitative shield pattern remained: zero-shot produced 10.4\% deterministic material violations, stress utility prompting 6.25\%, utility-only best-of-$N$ 4.2\%, ethics-aware best-of-$N$ 6.25\%, and rewrite shielding 0/48. The ethics-aware best-of-$N$ nano condition had a 6.25\% parse-failure rate, so cross-model comparisons should account for model-specific structured-output reliability.

A chunked seed-802 replication of the strongest stress arms completed after monolithic retries failed due to cluster network errors. In that replication, utility-only best-of-$N$ produced deterministic material violations in 4/48 episodes (8.3\%, CI [3.3, 19.6]\%), ethics-aware best-of-$N$ produced 0/48 (CI [0.0, 7.4]\%), and deterministic rewrite shielding produced 0/48 (CI [0.0, 7.4]\%). This supports the core direction of the stress result while reinforcing that zero deterministic shield rates require independent audit.

\paragraph{Audit calibration.}
Because the deterministic evaluator is intentionally narrow, we audited evaluator disagreements and used them to repair coverage, legal-status, and authority patterns. A refined LLM judge distinguishes affirmative false statements, misleading half-truths, permissible silence, permissible settlement authority or valuation negotiation, and true material facts. On a 400-row stress-inclusive audit sample after repair, the deterministic evaluator flagged 6.75\% of rows and the LLM judge flagged 5.5\%. The 44-row union of pre-repair flagged rows was adjudicated using scenario facts and both evaluator outputs. Against those adjudicated labels, the repaired deterministic evaluator had precision 0.783, recall 1.000, and F1 0.878, while the LLM judge had precision 0.545, recall 0.667, and F1 0.600.

The disagreement pattern is substantively useful. The deterministic evaluator overflags true policy-limit statements such as correctly stating both primary and umbrella coverage, but misses legal-status and client-authority formulations. The LLM judge better catches client-authority, legal-status, procedural-status, and damages issues, but overcalls some permissible settlement posture and true coverage statements. We therefore report deterministic results as a conservative automated measurement pass rather than as final ground truth, and use adjudicated audit subsets to estimate label uncertainty.

\paragraph{Stratified shield audit and blindspot stress.}
We additionally constructed a 400-row stratified audit packet spanning shield rewrite, warn-only, base stress prompting, utility best-of-$N$, and ethics-aware best-of-$N$ outputs. This packet is intentionally enriched for risky candidate rows and should not be read as a prevalence estimate. On this enriched packet, the deterministic evaluator marked 42.3\% of rows as material violations (Wilson 95\% CI [37.5, 47.1]\%). A GPT-4.1 judge marked 26.8\% (CI [22.6, 31.3]\%); binary agreement was 74.0\% (CI [69.5, 78.1]\%), with deterministic-vs-judge precision 0.509 and recall 0.804. The packet includes scenario facts, deterministic outputs, LLM-judge outputs, and optional adjudication fields for later external review.

The blindspot stress split tests whether a deterministic shield overfits known phrase rules. It includes unresolved medical liens, withdrawn expert support, denied insurance funding, and required approval authority. In the first 4-scenario run, both stress utility prompting and shield rewriting produced 0/4 deterministic material violations. However, the LLM judge flagged 2/37 audited utterances (5.4\%, CI [1.5, 17.7]\%), both in the withdrawn-expert scenario: the base stress model claimed the expert analysis remained robust, and the shielded model claimed the expert currently maintained a no-causation position.

We then expanded this blindspot family to 24 scenarios and added utility-only and ethics-aware best-of-$N$ arms. Deterministic episode-level material misrepresentation remained 0/24 in all four arms, so the deterministic upper bound is still wide (Wilson 95\% upper bound 13.8\% per arm). A GPT-4.1 judge audit over 1,000 sampled transcript and candidate rows flagged 160 rows (16.0\%, CI [13.9, 18.4]\%) while the deterministic evaluator flagged 0/1,000 (CI [0.0, 0.38]\%). A transcript-only audit flagged 63/390 final emitted rows (16.2\%, CI [12.8, 20.1]\%), including 10/85 sampled shield-rewrite transcript rows (11.8\%, CI [6.5, 20.3]\%). This makes the shield result a case study in evaluator overfitting, not evidence of solved mitigation: if the deterministic evaluator does not recognize a paraphrased false fact or misleading half-truth, the rewrite shield may pass it through.

As a robustness check, we also ran a second independent judge model, GPT-4.1-nano, over the earlier stratified and blindspot audit packets. That judge flagged 0/400 and 0/37 rows, respectively. We therefore treat it as a low-sensitivity bound rather than adjudicated ground truth. For the 400-row stratified packet, the automated two-model panel gives an any-judge rate of 107/400 (26.8\%, CI [22.6, 31.3]\%), but majority-judge and unanimous-judge rates of 0/400 (CI [0.0, 1.0]\%), making judge sensitivity itself an explicit result. We therefore added a stronger within-model sensitivity check using GPT-4.1 default, strict, and sensitive rubrics over rows flagged by the default GPT-4.1 judge. The flagged blindspot rows largely survive this check: 152/160 mixed transcript/candidate rows have majority-rubric support (95.0\%, CI [90.4, 97.4]\%), and 58/63 transcript rows have majority-rubric support (92.1\%, CI [82.7, 96.6]\%). A separate o4-mini judge flags 11/63 of these transcript rows (17.5\%, CI [10.0, 28.6]\%), so the independently supported set is smaller but still nonzero under a deterministic rate of 0/390. For verifier-shield residuals, GPT-4.1 rubric variants give majority support to 4/4 rows, but o4-mini flags 0/4 at severity at least 3; we therefore describe the verifier shield as a strong mitigation with uncertain residual risk rather than a solved guarantee. The current repository reports a claims table separating deterministic episode rates, single-judge row rates, transcript-only rates, candidate-only rates, automated multi-judge sensitivity rows, and optional external-adjudication slots.

\paragraph{Fact-grounded verifier shield.}
The deterministic shield failures motivate a stronger mitigation baseline that verifies proposed public messages against scenario facts before release. We therefore add an LLM-verifier shield using the same fact-grounded judge rubric as the independent audit, then rerun the 24-scenario blindspot split with utility and utility best-of-$N$ bases. Table~\ref{tab:verifier-shield} compares the original blindspot audit with the verifier-shield audit. GPT-4.1 flags fall from 63/390 unverified transcript rows (16.2\%, CI [12.8, 20.1]\%) to 4/196 verifier-shield transcript rows (2.0\%, CI [0.8, 5.1]\%). The residual 4 rows survive GPT-4.1 rubric-majority review but not the conservative o4-mini audit, so we treat verifier shielding as a promising mitigation baseline whose residual risk is uncertain rather than solved.

\section{Remaining Work}

The acceptance-critical remaining work is label validation and presentation polish. Because no external legal reviewer is currently available, the paper should not rely on human-adjudicated rates. Instead, the repository now reports automated sensitivity analyses using GPT-4.1 rubric variants and an independent o4-mini judge, while retaining review packets for optional later external validation. The next strongest validation step is a small external expert review or another strong non-OpenAI judge, not more deterministic runs. The completed chunked seed-802 replication should also be extended with at least one more seed or model replication if budget allows, because the direction is stable but confidence intervals remain wide. Every headline claim should remain traceable to \texttt{paper/tables/headline\_claims.csv}, which records the evaluator, denominator, confidence interval, and adjudication status.

\section{Limitations}

The current scenarios are synthetic and intentionally narrow. The deterministic evaluator is useful for replayable measurement but insufficient for broad language variation, and the current audit shows both false positives and false negatives. Deterministic shield results are especially vulnerable to detector overfitting because the shield and headline deterministic metric share evaluator logic. The verifier shield reduces GPT-4.1 flags in the blindspot split, but it inherits the costs and uncertainties of LLM-as-judge evaluation and should not be read as a formal guarantee. The benchmark taxonomy is inspired by professional-responsibility rules, especially truthfulness in negotiation, but it is not a jurisdiction-specific legal standard. Stronger paper claims require larger scenario coverage, cross-model replication, and independent LLM-judge sensitivity checks; external human or legally trained annotation would strengthen the evidence but is not treated as available ground truth here.

\section{Conclusion}

SettlementEthicsGym operationalizes a narrow but important safety question for legal agents: whether optimization for settlement outcomes amplifies material misrepresentation. The implementation establishes an executable environment, deterministic and LLM-judge evaluators, real LLM agents, control conditions, stress conditions, candidate-level audit logs, mitigation baselines, and a paper pipeline. Initial real LLM results support the benchmark's core premise: stronger utility pressure can surface unsafe negotiation statements, deterministic safety metrics can miss paraphrased failures, and fact-grounded verifier shielding can substantially reduce but not eliminate judge-flagged transcript risk.
